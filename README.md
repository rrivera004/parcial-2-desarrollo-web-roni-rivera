# Módulo de Capacitaciones - Mini RRHH

## Descripción

Se agregó un módulo para poder administrar las capacitaciones de la empresa.

Permite crear, editar, consultar y eliminar capacitaciones, además de buscar y filtrar por estado.

## Funcionalidades

- Ver capacitaciones
- Buscar capacitaciones
- Filtrar por estado
- Crear capacitaciones
- Editar capacitaciones
- Eliminar capacitaciones
- Ver estadísticas
- Validar los formularios
- Ruta protegida de capacitaciones

## Estados

- Programada
- En curso
- Finalizada
- Cancelada

## Tecnologías

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- TanStack Query
- Axios
- React Hook Form
- Zod
- Zustand
- JSON Server
